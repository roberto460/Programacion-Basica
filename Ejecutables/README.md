¿Qué significa los directorios creados?
Cuando conviertes un script de python en un ejecutable .exe usando pyintaller, al copilarlos genera dos carpets buil y dist. Carpeta build: Contiene archivos temporales creados durante el proceso de compilación. Sirve como espacio de trabajo para ensamblar el ejecutable, pero no es necesaria después de la creación del .exe. Carpeta dist: Aquí se encuentra el .exe final junto con los archivos y bibliotecas necesarias para que funcione correctamente en otro sistema. Si necesitas distribuir tu programa, esta es la carpeta que debes compartir.
